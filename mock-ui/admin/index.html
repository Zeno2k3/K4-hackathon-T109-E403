Đang xử lý slide

Mô phỏng pipeline — không gọi LLM thật, chỉ minh hoạ luồng xử lý theo flow-b-upload-slide.mermaid.

  1. OCR Service xử lý từng trang slide
  2. Extract dữ liệu text từ từng trang slide
  3. LLM phân tích text của từng trang
  4. LLM xác định thuật ngữ quan trọng trong trang slide
  5. LLM tạo giải thích cho từng thuật ngữ
  6. Hệ thống tổng hợp danh sách thuật ngữ + định nghĩa
