Mock VLearn UI

Hướng dẫn:
- Mở file `index.html` trong thư mục `mock-ui` bằng trình duyệt để xem giao diện.
- Giao diện giả lập: chọn tài liệu ở cột bên trái, điều hướng trang ở giữa, chat bên phải.
- Các chức năng hoạt động local: bôi đen (nhấp vào slide khi bật chế độ), ghi chú (nhập văn bản), gửi chat và tóm tắt.
